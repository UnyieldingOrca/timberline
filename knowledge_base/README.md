# Knowledge Base

This directory is the default location for Timberline's agent knowledge base.
The agent stores findings, patterns, and learned context here between runs.

## Structure

- `findings/` - Per-run analysis results
- `patterns/` - Recurring patterns and error signatures
- `services/` - Per-service learned context
- `config/` - Discovered namespaces, labels, thresholds
- `meta/` - Run metadata (last-run.json, etc.)
